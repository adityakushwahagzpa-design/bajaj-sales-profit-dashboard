# Bajaj | Sales & Profit Dashboard (2018–2021)

A sales and profit dashboard for Bajaj's CEO and CFO, set up as a hypothetical case on the public US Superstore dataset: **9,982 order lines (2018–2021)** across 4 regions, 49 states, 17 sub-categories and 793 customers. Built end-to-end with Claude AI.

## What was done
- **Data cleaning:** removal of 11 invalid sales rows and 1 duplicate
- **Executive dashboard:** 9 KPI cards, 14 charts, 10 filters and a year-on-year view
- **Web version:** cross-filtering, so a click on one chart filters the rest

## Key findings
- Discounts above 20% lost **$135.0K** across 1,391 order lines
- Tables, Bookcases and Supplies all run at a loss
- 10 states lose **$97.9K** between them
- **Recommendation:** CFO sign-off for any discount above 20%

## Tools
Claude AI · MS Excel

## Note
Superstore is public sample data; the Bajaj setting is a hypothetical case study.
